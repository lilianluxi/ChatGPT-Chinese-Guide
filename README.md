在使用第三方服务之前，建议确认：

1. 网站是否明确说明运营主体
2. 是否具有清晰的隐私政策
3. 是否说明实际提供的 AI 模型

5. 是否提供账户及数据管理方式

不要在来源不明的网站中提交密码、API Key 或其他敏感信息。

## ChatGPT 镜像和官方 ChatGPT 有什么区别？

两者不能简单地画等号。

官方 ChatGPT 是 OpenAI 提供的产品，而通常所说的“ChatGPT 镜像”“ChatGPT 中文镜像”或第三方 AI 聚合网站，则由其他运营者提供。

不同服务在以下方面可能存在区别：

| 项目 | 官方服务 | 第三方服务 |
|---|---|---|
| 运营方 | OpenAI | 第三方运营者 |
| 模型 | 以官方实际提供为准 | 取决于服务商 |
| 中文对话 | 支持 | 通常支持 |
| 网页使用 | 支持 | 通常支持 |
| 价格 | 以官方价格为准 | 各平台不同 |
| 隐私政策 | OpenAI 官方政策 | 取决于运营者 |

因此，在选择任何第三方 AI 服务之前，都应该了解其实际运营情况。
